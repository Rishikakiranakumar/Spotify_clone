Spotify Clone 🎵

A Spotify-inspired web player UI built using HTML and CSS,with a responsive layout for different screen sizes.

💻 Github Repository:https://github.com/Rishikakiranakumar/Spotify_clone
🔗 Live Link:https://rishikakiranakumar.github.io/Spotify_clone/


📌 About the Project

This project recreates the basic layout and visual design of a Spotify web player. It was built as a frontend learning project to practice web page structure, styling, responsive design, and basic JavaScript interactions.

🛠️ Technologies Used
1.HTML5
2.CSS3
3.Javascript
4.Font Awesome
5.Google Fonts

✨ Features
1.Spotify-inspired sidebar
2.Home and Search navigation
3.Your Library section
4.Playlist and podcast cards
5.Recently Played section
6.Trending section
7.Featured Charts section
8.Music player UI
9.Playback progress bar
10.Responsive layout for different screen sizes
11.CSS media queries for mobile-friendly layouts
12.Basic JavaScript interaction for the mobile menu toggle


🎯 Learning Goals
Through this project, I practiced:

1.Structuring web pages using HTML
2.CSS Flexbox for layout design
3.Responsive web design using CSS media queries
4.Fixed positioning and layout management
5.Styling cards, navigation, and player components
6.DOM selection and event listeners in JavaScript
7.Using classList.toggle() to control menu visibility
