Spotify Clone 🎵

A Spotify-inspired web player UI built using HTML and CSS.

📌 About the Project

This project recreates the basic layout and visual design of a Spotify web player. It was built as a frontend learning project to practice creating structured layouts and styling them with CSS.

🛠️ Technologies Used
1.HTML5
2.CSS3
3.Font Awesome
4.Google Fonts

✨ Features
1.Spotify-inspired sidebar
2.Home and Search navigation
3.Your Library section
4.Playlist and podcast cards
5.Recently Played section
6.Trending section
7.Featured Charts section
8.Music player UI
9.Playback progress bar


🎯 Learning Goals
Through this project, I practiced:

1.HTML page structure
2.CSS Flexbox
3.Responsive design
4.Fixed positioning
5.Layout and spacing
6.Styling cards and navigation components
7.Creating a music player interface
